# `./mindset`

Most people ask:

```text
"Which model should I use?"
```

I usually want to ask:

```text
"What is the actual problem?"
        ↓
"What data do we have?"
        ↓
"Can we trust the data?"
        ↓
"Do we even need an LLM?"
        ↓
"Where does retrieval fail?"
        ↓
"How do we evaluate the answer?"
        ↓
"What happens when this reaches 10,000 users?"
```

Because:

> **AI is not just a model.
> AI is a system.**

## `chat-with-documents`

The classic question:

> **"Can an LLM answer from my documents instead of hallucinating?"**

So I built the pipeline:

```text
DOCUMENT
   ↓
LOADER
   ↓
CHUNKING
   ↓
EMBEDDING
   ↓
VECTOR STORE
   ↓
RETRIEVAL
   ↓
CONTEXT
   ↓
LLM
   ↓
ANSWER
```

And then the interesting questions begin:

```text
Is the chunk too large?
Is the chunk too small?
Did retrieval find the right context?
How many chunks should we retrieve?
What if the answer spans multiple chunks?
How do we evaluate retrieval?
How do we evaluate generation?
```

That's where **RAG becomes engineering instead of a demo.**
